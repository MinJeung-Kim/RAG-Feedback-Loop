# 나만의 한국어 LLM 만들기 (학습 로드맵)

직접 모델을 다운받아 학습시켜 "내가 원하는 한국어 Q&A LLM"을 만드는 단계별 실습입니다.
NVIDIA GPU가 없는 PC를 기준으로, **Google Colab 무료 GPU(T4)** 에서 돌리는 것을 전제로 합니다.

## 큰 그림: 왜 두 단계인가?

LLM을 "만든다"는 건 보통 두 가지 의미예요. 둘은 난이도와 목적이 완전히 다릅니다.

| | from scratch (밑바닥부터) | 파인튜닝 (Fine-tuning) |
| --- | --- | --- |
| 의미 | 빈 모델을 처음부터 학습 | 똑똑한 오픈모델을 내 데이터로 미세조정 |
| 필요 자원 | 수천억 토큰 + 대형 GPU 수십~수천 장 | 작은 데이터 + GPU 1장 |
| 개인 실현성 | ❌ 비현실적 (원리 학습용 초소형만 가능) | ✅ 현실적 |
| 우리 목적 | **트랜스포머가 어떻게 동작하는지 이해** | **실제로 쓸 수 있는 한국어 챗봇** |

그래서 순서는:

```
1단계  01_tiny_gpt.ipynb     ── 초소형 GPT를 밑바닥부터 구현·학습 (원리 이해)
          └ 토크나이저 / 셀프어텐션 / 학습루프 / 텍스트 생성을 직접 만들어 봄

2단계  02_finetune_lora.ipynb ── 진짜 오픈모델(Qwen)을 LoRA로 한국어 Q&A에 미세조정
          └ 다운로드 → 데이터 정리 → 학습 → 추론 테스트 → 저장

3단계  통합                    ── 학습한 모델을 이 VectorDB(RAG) 프로젝트에 연결
          └ vLLM로 서빙하고 .env의 VLLM_MODEL을 내 모델로 교체
```

## 진행 방법

1. 이 `train/` 폴더의 `.ipynb` 파일을 [Google Colab](https://colab.research.google.com/)에 업로드
2. 상단 메뉴 **런타임 → 런타임 유형 변경 → T4 GPU** 선택
3. 셀을 위에서부터 순서대로 실행하며 마크다운 설명을 읽기

## 핵심 개념 미리보기

- **토큰(token)**: 모델이 읽는 최소 단위. 글자 또는 단어조각.
- **임베딩(embedding)**: 토큰을 숫자 벡터로 바꾼 것.
- **셀프 어텐션(self-attention)**: 문장 안에서 어떤 단어가 어떤 단어를 "참고"할지 계산하는 핵심 연산.
- **LoRA**: 거대한 모델 전체 대신 아주 작은 추가 가중치만 학습해서, 적은 GPU로 파인튜닝하는 기법.
- **SFT(Supervised Fine-Tuning)**: "질문 → 좋은 답변" 쌍을 보여주며 따라 하게 가르치는 학습 방식.
